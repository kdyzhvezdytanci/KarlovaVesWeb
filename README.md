# Karlovka

Minimal editorial website built with Next.js, Tailwind CSS, Framer Motion, and Lucide icons.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Upload all files in this project to a GitHub repository.
2. In Vercel, select **Add New → Project**.
3. Import the GitHub repository.
4. Keep the detected Next.js defaults and select **Deploy**.

Placeholder images are loaded from picsum.photos. Replace the image URLs in `app/page.js` with your own permanent images when ready.
